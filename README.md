# Panel Administrador — Frantz TopUp SPA

Versión visual inicial preparada para continuar el desarrollo.

## Incluye
- Login de administrador (demo visual)
- Dashboard
- Gestión de agentes
- Registro de operaciones
- Control de saldos
- Comisiones
- Configuración
- Diseño responsive para celular y computador

## Ejecutar
Abre `index.html` en un navegador.

## Próxima integración recomendada
Para producción se debe conectar a un backend/base de datos y agregar autenticación segura, roles, comprobantes, auditoría y API.
